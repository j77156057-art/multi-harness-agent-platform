目标：**平台助手能取到更深的取证材料**（更长的输出、stderr、出处、已脱敏）。

为什么：仓库主人圈了「助手的适配体检 + 声明草案、助手的深取证档」——这一张做后者。

现在助手手上的取证是 `task.diagnose`：**输出尾巴**（32KB / 200 行）+ 最近 3 条失败事件。
够回答「这单成没成」，不够回答「它卡在哪一步」。

范围：

- `backend/app/adapter/cli_output.py`：读尾巴时**按行脱敏**（像凭据的行遮挡掉，助手
  看不到原文），并报出遮挡了几行。
- `backend/app/api/routes.py`：新读面 `GET /tasks/{task_id}/forensics`（read 路由，无鉴权）——
  更长的输出（上限有界）、stderr、失败事件、**出处**（哪条任务/哪一轮/哪个日志文件/多少
  字节/多少行/什么时候）。
- `backend/app/assistant/tools.py` + `prompts.py`：新只读工具 `task.forensics` 与它的姿势。

**不碰** `docs/spec/**`、不碰权限矩阵、不动其他 Harness 的工作区与分支。

## 怎么做到不出错

1. **不翻译、不改写**：给助手的是**原文**。仓库的规矩是「人话翻译只给人」
   （`wording:read` 只给 human）—— 助手拿到原文自己说话，但平台不做翻译。
2. **脱敏在平台这一侧**：像凭据的行由平台先遮挡，助手**看不到**被遮挡的内容；
   回答里要说明「遮挡了几行」，不能装作没有。
3. **有界**：尾巴有上限（字节与行数），不能一次把 5MB 灌进模型。
4. **出处**：每份材料都要带「哪条任务、哪一轮、哪个文件、多大、什么时候」——
   没有出处的数字不许写进结论。
