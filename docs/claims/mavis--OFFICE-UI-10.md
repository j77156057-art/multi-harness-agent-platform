目标：**第一次用的人有路** —— 空项目里的空状态说人话、给一个能点的下一步；把界面上
的机器词换成人话；私聊发出去后说清楚「在等」。

为什么（真走一遍发现的，不是推演）：

1. 新建一个空项目，办公室中间那一大块白纸上写着「选一条任务看它的规格、事件轨迹和
   CLI 原话」—— **可一条任务都没有**。第一次用的人被要求去找一个不存在的东西。
2. 空项目里左栏摆着「全部 / 等人接 / 正在做 / 等人处理 / 没做成 / 按人 / 按时间 /
   排序 / 每页」外加「第 0–0 条，共 0 条」和两个点不动的翻页按钮 —— **全是没有对象的
   开关**，比界面真正要说的那件事还显眼。
3. 同一件事说了两遍：顶栏「今天这个项目还没有动静 —— 这个项目还没有任务」，
   左栏又说「本项目还没有任务。去顶栏的「开工配置」写一句你要做的事…」。
4. 项目配置表单里摆着「成员 Harness」「Harness 成员 · online」「正式项目范围：
   112 / office-formal-2 · 7 个可领活的成员窗口」—— 全是给机器看的词与 id。
5. 大厅那三步引导写的是「填写项目名称与成员 / 直接进入开工配置 / 开工向导里挑管理员
   和成员」，而界面上真的按钮只有「新建项目 / 连接工作窗口」，对不上。
6. 私聊发出去以后，界面上只有自己那条消息挂着，**没有一句话说「在等」**。管理员回话
   要过一次模型（慢），主人不知道是丢了还是在等。

范围：

- `office/src/flat-office.js`：空项目的顶部指引、今天那段、左栏空状态与中间栏；
  没有活可筛时收起筛选条/分页条；右栏「没有能干活的人」说清怎么办；
- `office/src/main.js`：给办公室一个「去写第一件事」的出口（打开开工向导）；
- `office/src/project-workspace.js`：项目配置表单与大厅三步的机器词/对不上的引导；
- `office/src/direct-chat.js` + `direct-chat.css`：私聊的等待提示；
- `office/scripts/verify-office-firstrun.mjs`：新增冒烟（自带静态服务器 + 拦全部 API）。

不碰 `backend/**`（这一轮**只改说话与引导**，不动平台行为）、`docs/spec/**`、
`backend/migrations/**`、其他 Harness 的工作区与分支。

## 怎么做到不出错

1. **每一处都只说一件事**：顶部说「现在是什么 + 下一步点哪里」，左栏说「还没有活」，
   中间栏说「这一栏将来会出现什么」，不再三处各说一遍。
2. **不改既有断言的意图**：`verify-office-project-scope.mjs` 断言空状态含
   「还没有任务」—— 新文案保留这句话（只是不再重复后面那一整段）。
3. **空项目才生效**：筛选条/分页条只在**一条任务都没有**时收起；有活可筛时原样不动。
4. **按钮要真的能点**：不是画一个假的「去写第一件事」，而是打开真的开工向导
   （`openingHost.open()`），并用冒烟钉住「点了之后向导确实打开了」。
5. **私聊的提示按事实来**：只有「最后一条确实是我发的、还没人回」才显示「在等」；
   管理员一回复就不再显示。
