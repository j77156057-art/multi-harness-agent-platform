目标：**窗口页给这个窗口的活列一份详细清单** —— 写明具体是做什么的，**不截断**，
收成卡片，点开即看。

为什么：仓库主人：「给各个 harness 页面添加任务详细清单，要写明具体是做什么的，不要截断，
收缩成卡片，点开即看」。现在窗口页只有一行标题（`titleParts(task).main` 是主句，细节被切掉），
人看不出这条活到底要做什么。

范围：

- `office/src/flat-office.js`：窗口页的活清单改成**可展开的卡片**；展开时显示这条活
  **完整的目标原文** + 验收标准 + 只允许改的路径 + 这条活的经过；
- `office/src/flat-office.css`：卡片样式（目标原文不截断、可换行）；
- `office/scripts/verify-office-conversations.mjs`：补断言。

数据：**目标原文不在任务列表里**（`/tasks` 的行只有 title/status/owner/…），它在
`/tasks/{id}` 的 `spec.goal` 里 —— 所以**按需取**：点开哪条才去读哪条，读过一次缓存一分钟，
不拖慢列表。

不碰 `backend/**`（这一卡纯前端）、`docs/spec/**`、其他 Harness 的工作区与分支。

## 怎么做到不出错

1. **不截断**：目标原文整段摆出来（`white-space: pre-wrap` + `overflow-wrap: anywhere`），
   不做「前 N 字 + …」。界面上已有的「路径只留文件名」是**另一件事**（那是给人看的简写），
   任务书原文照原样。
2. **点开即看**：点开的那一刻才去读 `/tasks/{id}`（`state.windowSpecs` 缓存 60 秒），
   失败要说清「读不到」，不能给一个空框让人以为这条活没有目标。
3. **收起时仍有用**：卡片收起时是「状态 + 标题 + 做到第几次 + 现在什么状态」，
   不用展开也知道这条活是什么。
4. **事件按这条活取**：窗口页底部那条「它的轨迹」是全局的；卡片里要的是**这条活**的经过
   （`aggregate_id` 匹配）。
