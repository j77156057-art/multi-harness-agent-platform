## 做什么

办公室头顶给一段**说人话的「今天」**：这个项目今天发生了什么。

现在头顶给的是**计数徽章**（等人接 1 / 正在做 0 / 等人处理 0 / 没做成 13 /
完成了 4）—— 那是**总共**几条，不是**今天**，而且得自己加。人的问题是"今天这个项目
怎么样了"，答案应该是一句话。

## 为什么

- 计数徽章是**总数**，人问的是**今天**。
- 徽章要人自己做减法；一句话不用。
- 「今天」和「现在该你做什么」是两件事，正好各占一行：导语说现在，那段说今天。

## 怎么做到不出错

1. **每句都是平台上的事实算出来的**，不是估的：
   - 今天新来的 —— 任务 `created_at` 落在今天；
   - 今天做完的 —— 状态是已完成、且 `updated_at` 落在今天；
   - 今天没做成的 —— 状态是没做成、且 `updated_at` 落在今天；
   - 现在在干的 —— 状态是 `claimed`/`in_progress`/`verifying`；
   - 额度用了多少次 —— 平台给的 24 小时用量时间线。
2. **"今天"按本机时区算**：办公室跑在人的浏览器里，他说的"今天"就是他那边的今天。
   平台的时间戳是 UTC，直接比会差八小时。
3. **额度单独一句**：额度是**全平台**的用量，不是这个项目的账，不能混进这句话里。
4. **时间线盖不满今天时就说"最近一天"**：平台给的是最近 24 小时，早晨时它盖不满
   今天 —— 那就不假装它是"今天"。
5. **今天没动静也要说话**："最新的一条是 3 天前更新的"比空着有用 —— 人要知道是
   刚清空还是躺了三天。
