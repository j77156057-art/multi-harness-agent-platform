## 四、方案 C 落地后仍需保留的机制

去掉序号**不等于**去掉唯一性检查。以下三条要保留（换判据，不换意图）：

| 现判据 | 落地后判据 | 状态 |
|---|---|---|
| 认领文件序号唯一 | 认领文件 `task_id` 唯一（**大小写不敏感**，Windows 约束） | 需新增 |
| 认领文件名 task_id ↔ 内容一致 | 原样保留 | ✅ 已存在 |
| 占用序号表路径格式 | — | 删除 |
| 占用序号表不撞号 | — | 删除 |

提案第 3 条反对意见已经指出：**task_id 唯一性断言必须改成大小写不敏感比对**，
否则 Windows 上`<A>.md` 与 `<a>.md` 会撞而在 Linux 不会，断言抓不到。
今天数据无此情况，但断言要按未来的正确形态写。

另有一个提案提到的盲区仍然成立：`docstate` 不校验认领登记表的注释行，
迁移时若注释指向的文件不存在，不会立刻变红。**建议同步补一条。**
